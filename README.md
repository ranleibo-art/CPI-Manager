# מנהל מדדים — מדד המחירים לצרכן (הלמ"ס)

דשבורד עצמאי לצפייה במדד המחירים לצרכן בכל הבסיסים, המתעדכן אוטומטית מהלשכה
המרכזית לסטטיסטיקה (הלמ"ס). כל הערכים מוצגים לפי המספרים הרשמיים של הלמ"ס —
הבסיסים אינם מחושבים במקדם מעוגל אלא נגזרים ממקדמי הקישור המדויקים של הלמ"ס.

## מה יש כאן

```
index.html                     הדשבורד (עמוד יחיד, ללא תלות חיצונית)
data/IL.json                   נתוני המדד — מתעדכן אוטומטית מהלמ"ס
scripts/update_cbs.py          מושך מהלמ"ס וכותב את data/IL.json
.github/workflows/update-cpi.yml   ריצה חודשית אוטומטית (GitHub Action)
```

## הקמה ב-GitHub Pages (חד-פעמי, ~5 דקות)

1. צרו repository חדש ב-GitHub (מומלץ **Public** — Pages בחינם; הנתונים ממילא ציבוריים).
   לדוגמה בשם `cpi-manager`.
2. העלו לתוכו את כל הקבצים מהתיקייה הזו (גרירה ל-"Add file → Upload files", כולל
   תיקיית `data`, `scripts` ו-`.github`).
3. **Settings → Pages →** תחת *Build and deployment*, ב-*Source* בחרו **Deploy from a branch**,
   ענף `main`, תיקייה `/ (root)`, ולחצו **Save**.
4. אחרי דקה-שתיים הדף יהיה זמין בכתובת:
   `https://<שם-המשתמש>.github.io/cpi-manager/`
   זה הלינק שתשתפו — כל מי שנכנס רואה את הנתונים העדכניים, בלי להתקין דבר.

## עדכון אוטומטי חודשי

ה-Action רץ מדי חודש ב-15–18 בו (אחרי פרסום הלמ"ס ב-15 בחודש), מושך את המדד החדש,
ומעדכן את `data/IL.json`. לאחר מכן GitHub Pages מגיש אוטומטית את הנתון החדש.
אין צורך בשום פעולה ידנית.

* הרצה ידנית מיידית: לשונית **Actions → Update CPI data from CBS → Run workflow**.
* צריך שההרשאה תהיה פעילה: **Settings → Actions → General → Workflow permissions →
  "Read and write permissions"**.

## אימות (מומלץ פעם אחת אחרי ההרצה הראשונה)

השוו את הערך של החודש האחרון בטבלה החודשית מול אתר הלמ"ס
(מדדי מחירים → מדדים עיקריים). הזרע הנוכחי מדויק עד **יולי 2026**
(מדד 2018=100 → 119.8958, שינוי חודשי 0.3%, שנתי 1.5%).

## הערה טכנית

`scripts/update_cbs.py` קורא מ-`https://api.cbs.gov.il/index/data/price?id=120010`
(קוד 120010 = מדד המחירים לצרכן, כללי). הפירסור גמיש; אם הלמ"ס תשנה את מבנה
התשובה, אפשר לעקוף את הכתובת דרך משתנה הסביבה `CBS_URL`, ואת קוד הסדרה דרך `CBS_CODE`.
